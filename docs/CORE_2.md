# Core 2: information flow through pure derivations

24 September 2026. This adds one expression to the inert JSON program: `{"name":"message","concat":["prefix","patient"]}`. Program and host manifest have `version: 2`; the program contains exactly `version`, `derive` and `actions`. Host inputs carry initial labels, values and grants. Core 2 statically evaluates derivations in list order; it never evaluates arbitrary Python source, imports, callbacks, conditionals or loops from the program.

Abstract value (v=(s,O)), where (s\in\{Public,Sensitive\}) and (O) is the finite set of source input names. `concat(v1,...,vn)` has label Sensitive if **any** operand is Sensitive and origins (O_1\cup\dots\cup O_n). There is no sanitization, declassification or endorsement operation. The send rule is the same narrow Core 1 rule, applied to the **derived value name**: a sensitive `message` sent to recipient `r` requires a host-issued grant for `(r,message)`; a grant for the input name `patient` does not suffice. Unknown operands, dynamic effects and unknown recipients yield UNKNOWN with a reason. Invalid syntax and duplicate declarations are rejected. Known violating sends take precedence over unknown actions, as in the earlier checker.

The minimal inductive property is: if a labeled sensitive input occurs in any successfully resolved chain of concatenations producing a value, that value remains Sensitive. Base case: its host label is Sensitive. Induction step: the join rule returns Sensitive if any operand is Sensitive. A send of that value cannot obtain conditional PROVED without a host grant matching its name and recipient. This is a reasoning statement **for the restricted abstract program**, under honest labels, immutable grants and complete effect mediation. It says nothing about branch-dependent implicit flows, content-based transformations, real network effects, or whether granting disclosure was appropriate.

`agent_core/core2.py` returns a diagnostic, origin sets, a public program digest and host-keyed manifest MAC; it deliberately exposes no input text in `Core2Result`. It does not execute sends. Tests cover derived taint, recipient and grant substitution, unknown dependencies, forward references, unsupported branches, duplicate declaration, and all four combinations of two operand labels. The examples are `examples/core2-program.json` and `examples/core2-host.json`.

This is an actual extension of the candidate's semantics, but still fails the comparison gate: ordinary existing languages can implement taint propagation and the trusted host can enforce the same narrow check. Distinctive syntax, new compiler back end, process confinement and replay protection have not been demonstrated or implemented.
